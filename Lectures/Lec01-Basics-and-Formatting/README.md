# Lec01: Basics and Formatting

**Workbook:** [Lec01-Basics-and-Formatting.xlsx](./Lec01-Basics-and-Formatting.xlsx)

In this lecture we get to know the Excel screen and build a neat, formatted **marksheet**.

## The Excel Screen

| Term | What it means |
|---|---|
| **Workbook** | The whole Excel file (`.xlsx`) |
| **Worksheet** | One page (tab) inside the workbook, e.g. `Sheet1` |
| **Cell** | One box where a row and a column meet |
| **Cell address** | Column letter + row number, e.g. `B3` |
| **Range** | A group of cells, e.g. `B3:G14` |
| **Ribbon** | The tabs and buttons at the top (Home, Insert, Formulas, Data…) |
| **Name Box** | Shows the address of the selected cell (left of the formula bar) |
| **Formula Bar** | Shows what is really inside the selected cell |

## Entering Data

* Click a cell and type. Press **Enter** to go down, **Tab** to go right.
* To edit a cell, double-click it or press **F2**.
* Numbers align to the right and text aligns to the left by default.

## Formatting the Marksheet

1. **Title:** type `MARKSHEET`, select the cells above the table (`B1:K2`) and click **Home → Merge & Center**.
2. **Headings:** type `ROLL NO`, `Name`, `Section`, `Sub 1`… and make them **bold**.
3. **Borders:** select the table and choose **Home → Borders → All Borders**.
4. **Colours:** use **Fill Color** for the title and heading row, **Font Color** for text.
5. **Column widths:** drag the line between column letters, or double-click it to **AutoFit**.
6. **Alignment:** centre the headings and numbers with the alignment buttons.

## Useful Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + B` | Bold |
| `Ctrl + S` | Save |
| `Ctrl + Z` | Undo |
| `Ctrl + 1` | Format Cells dialog |

## Common Mistakes

* Merging cells **inside** the data table. Merge only the title.
* Typing data with extra spaces before or after it.
